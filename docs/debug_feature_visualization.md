# デバッグ特徴量可視化仕様

## 目的

DINOv3から取得した5種類の特徴量をすべて可視化し、クロップ済み生画像とともに1枚のデバッグ画像で確認できるようにする。

## 入力と出力

- 入力:
  - クロップ済みRGB画像
  - `feature_block_1`〜`feature_block_4` の特徴量
  - 最終出力 `features`
- 出力: 既存のデバッグ画像生成フローで保存する、3列×2行の画像1枚。

## 動作

- 5つの特徴量それぞれを、既存のPCA-RGB方式で可視化する。
- 6枠を左から右、上から下に配置する。
  1. 左上: クロップ済みRGB画像
  2. 上段中央: `feature_block_1` の可視化
  3. 右上: `feature_block_2` の可視化
  4. 左下: `feature_block_3` の可視化
  5. 下段中央: `feature_block_4` の可視化
  6. 右下: 最終出力 `features` の可視化
- 保存先とファイル名は既存のデバッグ画像生成フローに従う。

## 制約とエラー時の扱い

- 特徴量抽出、特徴量の保存形式、デバッグ画像の保存先は本仕様では変更しない。
- 5つの特徴量のいずれかでPCA可視化に失敗した場合は、既存動作を踏襲してそのsampleの合成画像を保存せず、issueとして記録する。部分画像は保存しない。

## 関連実装

- `src/dinov3_pipeline/saving/cnn_bundle_exporter.py`: sample出力、PCA可視化の呼び出し、可視化エラーのissue記録。
- `src/dinov3_pipeline/saving/pca_visualizer.py`: PCA-RGB可視化。
- `src/dinov3_pipeline/dinov3/extractor.py`: 4つの中間層特徴量と最終特徴量の抽出。

## 受け入れ条件

- 5つすべての特徴量がPCA-RGB方式で可視化される。
- クロップ済みRGB画像1枚と特徴量可視化5枚が、指定順で3列×2行の1枚の画像に保存される。
- 既存の対象sampleのデバッグ画像生成フロー、保存先、およびファイル名が維持される。
